# Sprint 6 — UI-автотесты для сервиса «Яндекс Самокат»

## Описание проекта
Проект создан для автоматизации пользовательских сценариев веб-сервиса «Яндекс Самокат» — платформы аренды самокатов. Тестирование выполняется в браузере Firefox с использованием Selenium, pytest и Allure.

## Структура проекта
В корне репозитория размещены ключевые компоненты:

pages/ — Page Object-классы, отражающие структуру страниц сервиса.

tests/ — тестовые сценарии для разных частей веб-приложения.

locators/ — локаторы для элементов интерфейса.

data — тестовые данные, используемые в проверках.

conftest.py — настройки и фикстуры для запуска тестов.

allure_results/ — результаты прогонов тестов в формате Allure.

requirements.txt — зависимости проекта.

urls.py - ссылки на сервисы, используемые в тестах

README.md — документация и инструкции по запуску.

## Покрытие тестами
test_faq.py
Проверка корректной работы раздела «Вопросы о важном».

test_order.py
Позитивные сценарии оформления заказа:
тестирование с двумя наборами пользовательских данных;
запуск процесса из двух различных точек: кнопка «Заказать» в шапке и внизу страницы, а также переходов по логотипам:
на главную страницу сервиса, на «Яндекс.Дзен».

## ▶ Как запустить тесты
Установите зависимости:

```pip install -r requirements.txt```

Запустите все тесты:

```pytest -v```

## Генерация отчёта Allure
Для просмотра отчёта о тестировании в реальном времени:

```allure serve allure_results```
